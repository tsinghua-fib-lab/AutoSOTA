# Code of Conduct

This project has adopted the [Contributor Covenant][cc] as its Code of Conduct,
version 2.1, available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

[cc]: https://www.contributor-covenant.org/

All participants in this project — contributors, maintainers, and community
members — are expected to abide by its terms.

## Reporting

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported to the project maintainers via the contact address listed in the
repository's ownership information, or to Meta Open Source at
<opensource-conduct@meta.com>.

For FAQ on the Contributor Covenant, see
<https://www.contributor-covenant.org/faq>. Translations are available at
<https://www.contributor-covenant.org/translations>.
