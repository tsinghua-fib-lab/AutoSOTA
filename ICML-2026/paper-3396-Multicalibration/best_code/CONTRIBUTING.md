# Contributing to multicalibration_for_matching

We welcome contributions. This document describes how to propose changes.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code, add tests where reasonable.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes and `ruff check .` is clean.
5. Open a pull request.

## Contributor License Agreement (CLA)

In order to accept your pull request, we need you to submit a CLA. You only
need to do this once to work on any of Meta's open source projects.

Complete your CLA here: <https://code.facebook.com/cla>

## Issues

We use GitHub Issues to track bugs and feature requests. Please ensure your
description is clear and has sufficient instructions to reproduce the issue.
