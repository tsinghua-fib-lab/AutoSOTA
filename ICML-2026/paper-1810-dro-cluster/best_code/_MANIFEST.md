Release-ready ICML artifact skeleton: install metadata, README, code, data links, small result summaries, and tests.
- `.gitignore`: excludes datasets, generated intermediates, local environments, and editor state.
- `README.md`: short setup, reproduction, and data policy instructions.
- `pyproject.toml`: package metadata and dependency declaration.
- `requirements.txt`: pip-compatible dependency list.
- `data/`: external dataset links and local placement guidance.
- `docs/`: reproducibility matrix and experiment coverage notes.
- `results/`: small checked-in summary outputs only.
- `scripts/`: command-line reproduction entry points.
- `src/`: importable Python package.
- `tests/`: lightweight behavior checks for release code.
