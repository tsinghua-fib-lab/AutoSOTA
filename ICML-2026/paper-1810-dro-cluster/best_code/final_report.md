## Winning Changes (in _best)

Three changes combine to produce AMI 0.9661 (+5.76% from baseline):

### 1. CODE-04: Row-wise L2 Normalization (iter 2)
- **File:** src/dro_subspace/metrics.py:spectral_clustering()
- **Change:** Replaced heuristic sqrt(n_samples) embedding scaling with standard Ng-Jordan-Weiss row-wise L2 normalization
- **Impact:** +3.5% AMI (the single largest improvement)

### 2. ALGO-06b: 20-Seed Consensus KMeans (iter 5 → iter 12)
- **File:** src/dro_subspace/metrics.py:spectral_clustering()
- **Change:** Replaced single KMeans with co-association matrix from 20 independent KMeans runs, then cluster on co-association
- **Impact:** +1.5% AMI (10 seeds) → +2.2% (20 seeds, cumulative with other changes)

### 3. Affinity Thresholding at 50th Percentile (iter 8)
- **File:** src/dro_subspace/metrics.py:spectral_clustering()
- **Change:** Zero out affinity values below the per-row 50th percentile, then re-symmetrize
- **Impact:** +0.49% AMI (removes inter-cluster noise while preserving strong connections)

### Also present (no measurable impact in these experiments):
- CODE-01: Perturbation-based gradient descent restart (improves robustness for edge cases where GD doesn't converge)
