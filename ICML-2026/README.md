# ICML 2026 — AutoSOTA Optimized Repositories

This directory contains ICML 2026 paper repositories that were optimized by the AutoSOTA pipeline (tsinghua-fib-lab/AutoSOTA). 
(Continuously Updated)

Each `paper-<id>-<abbr>/` subdirectory holds:

- the slimmed source code of the original repository (datasets, weights,
  caches, and `.git/` history removed);
- when available, a `final_report.md` summarizing the AutoSOTA run, including
  the primary metric, number of records, generated timestamp, and best result
  (iteration, idea, metric, commit, and notes).
