# Paper Figures (generated)

This directory contains the paper-facing main figures.

## Contents

- `figure1_money_plot.(pdf|png)`: money plot (selected functions) with depth annotations
- `figure2_depth_fidelity_bubble.(pdf|png)`: depth–fidelity characterization (bubble plot)
- `figure3a_ranking.(pdf|png)`, `figure3b_single_crossing.(pdf|png)`, `figure3c_transfer.(pdf|png)`: ranking, single-crossing, and transfer panels
- `figure_rank_by_probe.(pdf|png)`: per-function mean rank by probe statistic P

## Reproduce

These figures are pre-generated. To regenerate them, run the relevant steps of
`tools/reproduce_all.py`; see `docs/FIGURES.md` for the plotting script and data
source behind each figure.
