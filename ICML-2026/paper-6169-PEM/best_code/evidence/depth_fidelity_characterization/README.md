# Depth–Fidelity Characterization

This package supports Figure 2 (depth–fidelity bubble plot) by summarizing the
fixed-budget trade-off between evaluation cost per candidate and effective depth.

## Artifacts

- `depth_fidelity_bubble.(pdf|png)`: bubble plot (cost vs performance; bubble size = depth)

## Reproduce

```bash
python3 tools/plot_depth_fidelity_bubble.py
```
