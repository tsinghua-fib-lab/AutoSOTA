# Hansen fixed-budget — Budget grid extension (B=50D / 100D / 200D)

Purpose: test robustness across budgets by rerunning the same high-misranking fixed-budget slice at multiple budget multipliers.

We rerun the same **high-misranking slice** (COCO `bbob-noisy`, `D=40`, instances `1–15`) at a small **budget grid**
and summarize the paired outcomes.

## Evidence layout

- Main fixed-budget pack (B=100D): `evidence/hansen_test_fixed_budget/`  
- Budget-grid packs (this folder):
  - `evidence/hansen_test_fixed_budget_grid/B50/`
  - `evidence/hansen_test_fixed_budget_grid/B200/`

Each pack contains:
- Money plots: `money_plot_noisefree_d40_B{B}_f8-10-14-20(_with_resample).png`
- Paired sign-tests (noise-free final best): `noisefree/pairwise_sign_test.csv`
- Paired sign-tests incl. fixed-k resampling: `noisefree/pairwise_sign_test_with_resample.csv`

## Cross-budget summary

- Table: `evidence/hansen_test_fixed_budget_grid/budget_grid_summary.csv`
- Plot: `evidence/hansen_test_fixed_budget_grid/winrate_vs_budget.png`

The plot reports BERW-Hetero’s win rate (paired sign-test) vs:
- `UH-CMA-ES(maxevals=30)` (evaluation-stage uncertainty reduction)
- `CMA-ES-Resample(k=10)` (fixed-k resampling baseline)

Generated by: `python3 tools/summarize_hansen_budget_grid.py --out-dir evidence/hansen_test_fixed_budget_grid --budgets 50,100,200`.
