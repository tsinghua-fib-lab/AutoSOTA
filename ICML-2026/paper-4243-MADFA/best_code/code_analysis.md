# Code Analysis: Paper 4243 — Mechanistic Anomaly Detection via Functional Attribution

## Evaluation Path
- `analyze.py` — loads `loss_traces.npz`, computes AUROC via `sklearn.metrics.roc_auc_score`
- Parses stdout: line matching `CLC              |  X.XXXX` → CLC_AUROC
- Detection: Mean Corr, CLC, Mean CCC, Class CCC (Pearson + CCC, mean/class-max aggregation)

## Training Path
- `train_backdoor.py` — trains PreActResNet18 with blended backdoor (5% poison, target class 0)
- `prepare_data.py` — splits CIFAR-10 test into trusted/sampling/test, copies bd_test_dataset

## SGLD Sampling Path
- `run_sgld.py` — uses devinterp `estimate_learning_coeff_with_summary` with RMSprop-SGLD
- `LossTraceCallback` records per-sample CE loss at every draw
- Hyperparameters: gamma=10000, nbeta=100, lr=1e-6, n_draws=2000, n_chains=1

## Config Path
- CLI arguments in `run_sgld.py` and `analyze.py` — no separate config file

## Metric Parser
- `analyze.py` stdout: regex-parseable lines
- Key metrics: CLC_AUROC, Mean_Corr_AUROC, Mean_CCC_AUROC, Class_CCC_AUROC

## Pre-downloaded Paper Data
- None mounted. CIFAR-10 at `/datasets/cifar10/cifar-10-batches-py/`

## Risky Files
- `loss_traces.npz` — 96MB, regenerated by `run_sgld.py`
- `data/` directory — contains model checkpoint and image splits

## Safe Modification Targets
- `analyze.py` — add new coupling measures, aggregation methods, diagnostics
- `run_sgld.py` — modify SGLD hyperparameters, add LR scheduler, add chains
- `train_backdoor.py` — modify backdoor training parameters (with regeneration)

## Known Bottlenecks
1. SGLD mixing quality unknown (no ESS/R-hat diagnostics)
2. Aggregation gap: Mean_Corr 0.9377 vs CLC 0.9999 suggests aggregation strategy matters
3. Single SGLD chain may limit posterior exploration
4. Fixed LR throughout sampling (no schedule)
5. Only Pearson/CCC coupling (no kernel/DTW measures)

## Red-Line Boundaries
- Must NOT change: evaluation command, metric computation, test data/splits, labels
- Must NOT hard-code outputs or change scoring scripts
- Must use `/tools/record_score.sh` for all score records
