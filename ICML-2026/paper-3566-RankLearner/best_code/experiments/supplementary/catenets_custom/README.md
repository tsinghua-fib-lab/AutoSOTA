# Custom CATENets

This directory contains a custom version of the CATENets library used for supplementary experiments in **Rank-Learner: Orthogonal Ranking of Treatment Effects**. The original CATENets repository by Alicia Curth et al. can be found at: `https://github.com/AliciaCurth/CATENets`.

## Notes

This is **not** the official CATENets repository. The code in this folder includes local modifications made specifically for the experiments in this repository.

The main changes include:
- implementation of Rank-Learner in the CATENets PyTorch framework,
- implementation of PairNet in the CATENets PyTorch framework,
- compatibility changes for the Rank-Learner experiments.

For the official implementation and documentation, please refer to the original repository linked above.
