# Custom TreeRanker

This directory contains a custom version of the code used for supplementary experiments in **Rank-Learner: Orthogonal Ranking of Treatment Effects**. The original TreeRanker repository by Fahad Kamran et al. can be found at: `https://github.com/MLD3/Learning-to-Rank-for-Optimal-Treatment-Allocation-Under-Resource-Constraints`.

## Notes

This is **not** the official TreeRanker repository. The code in this folder includes local modifications made specifically for the experiments in this repository. For the official implementation and documentation, please refer to the original repository linked above.
