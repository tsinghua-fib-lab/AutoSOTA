# Open Source Release Checklist

Before publishing the repository:

- [ ] Add CI/release badges to the README after the final GitHub repository path
      is known.
- [ ] Confirm the intended code license. The current code license is MIT.
- [ ] Verify that paper PDFs, extracted text, private reviews, and local logs are
      not committed unless redistribution is permitted.
- [ ] Verify that generated outputs are either intentionally committed as a
      release artifact or left out of Git and regenerated by scripts.
- [ ] Run `python3 -m pytest`.
- [ ] Run `./rebuttal_experiments/run_all_rebuttal.sh` if publishing regenerated
      evaluation outputs.
- [ ] Run `python3 paper_figures/make_revised_figures.py` if publishing figures.
- [ ] Search for private paths, credentials, tunnel URLs, and IP addresses:

```bash
rg -n "credential|token|tailscale|pinggy|192\\.168|10\\.[0-9]+|/home/" .
```

- [ ] If publishing on GitHub, create a release with generated PDFs/CSVs as
      downloadable artifacts rather than mixing large outputs into source.
