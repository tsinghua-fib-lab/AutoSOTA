# Code Analysis — Paper 4290: BREW Watermarking

## Evaluation path
- **Script**: `/repo/reproduce_eval.py`
- **Command**: `python3 reproduce_eval.py --max-samples 200 --model-path /models/facebook/opt-1.3b --seed 42`
- **Flow**: Load C4 samples → generate watermarked text → apply 10% synonym substitution → detect watermark → also generate unwatermarked + check natural text → compute TPR/FPR/Precision/F1
- **Output**: stdout (parsed after "REPRODUCTION RESULTS" header) and `/repo/results/BREW_repro/reproduction_summary.json`

## Key files
| File | Role | Safe to modify? |
|------|------|-----------------|
| `reproduce_eval.py` | Evaluation harness | Yes — config, generation params. No — metric computation, dataset loading |
| `watermark/BREW/BREW.py` | Core BREW implementation | Yes — logits processor, detection, codeword selection |
| `sage/all.py` | BCH codec shim (galois) | Yes — decode_to_code error handling |
| `config/BREW_paper.json` | Paper config (auto-generated) | Generated by eval script; OK to modify PAPER_CONFIG in eval.py |
| `dataset/c4/processed_c4.json` | C4 test data | DO NOT MODIFY |
| `synonym_attack.py` | Synonym substitution attack | DO NOT MODIFY (attack logic) |

## Metric parser
Parse lines matching `TPR (Recall):`, `FPR:`, `Precision:`, `F1:` after `REPRODUCTION RESULTS` header in stdout.

## Config path
`PAPER_CONFIG` dict in `reproduce_eval.py` → written to `config/BREW_paper.json` → loaded by `AutoWatermark.load()`

## Safe modification targets
1. `BREWLogitsProcessor.__call__()` — adaptive delta logic (A1)
2. `BREWUtils._find_distant_codeword_pair()` — codeword selection (C1)
3. `BREW.detect_watermark()` — erasure decoding (A3), threshold (C2), confidence scoring (A5)
4. `_BCHDecoder.decode_to_code()` — relaxed decode (A6)
5. `PAPER_CONFIG` dict — delta, temperature, top_p, top_k (P1, P2)

## Red-line boundaries
- Do NOT modify `dataset/c4/processed_c4.json`
- Do NOT modify metric computation in `run_reproduction()` (TPR/FPR/Precision/F1 formulas)
- Do NOT modify `synonym_attack.py` attack logic
- Do NOT hard-code per-sample detection results
- Do NOT change eval protocol (watermarked+attacked vs unwatermarked+natural text)

## Baseline
- TPR=0.995 (199/200), FPR=0.0, Precision=1.0, F1=0.9975
- 1 missed detection out of 200 watermarked samples
- All false positive checks pass on 400 unwatermarked+natural texts
