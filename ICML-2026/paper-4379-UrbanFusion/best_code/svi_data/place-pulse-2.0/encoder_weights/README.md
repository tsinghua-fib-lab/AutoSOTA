### Instructions for Baselines

- **SatCLIP**: Download the weights [microsoft/SatCLIP-ViT16-L10](https://huggingface.co/microsoft/SatCLIP-ViT16-L10) and [microsoft/SatCLIP-ViT16-L40](https://huggingface.co/microsoft/SatCLIP-ViT16-L40), then place them here.

- **CSP**: Download the following weights from [the official CSP website](https://gengchenmai.github.io/csp-website/) and place them here:  
  - `model_fmow_gridcell_0.0010_32_0.1000000_1_512_gelu_UNSUPER-contsoftmax_0.000050_1.000_1_0.100_TMP1.0000_1.0000_1.0000.pth`  
  - `model_inat_2018_gridcell_0.0010_32_0.1000000_1_512_leakyrelu_UNSUPER-contsoftmax_0.000500_1.000_1_1.000_TMP20.0000_1.0000_1.0000.pth`

- **GPS2Vec**: Download the weights from the [official GPS2Vec repository](https://github.com/yifangyin/GPS2Vec?tab=readme-ov-file). Place all models here in subfolders named `GPS2Vec_tag` and `GPS2Vec_visual`, respectively.
