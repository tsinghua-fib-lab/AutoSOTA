# MACD Codebase Analysis — SOTA Optimization

## Evaluation Path
- scripts/eval_macd.sh -> eval/run_macd_simple.py (inference) -> eval/evaluate.py (metrics)
- run_macd_simple.py uses standalone MACD implementation (NOT monkey-patched macd/decoding.py)
- Current defaults: cd_alpha=2.6, cd_beta=0.0036, temperature=0.7, top_p=0.9, top_k=50

## Key Files
- Inference (active eval path): eval/run_macd_simple.py — standalone MACD decoding, greedy argmax after CD+temp+topk+topp filtering
- Pipeline (manifest->r->cf): macd/optimization.py, macd/synthesis.py — not directly used by eval, counterfactual videos pre-generated
- Legacy inference: eval/run_video_vqa.py — uses monkey-patched macd/decoding.py (not used by current eval)
- Config: scripts/eval_macd.sh — hardcoded CD_ALPHA, CD_BETA, temperature, top_p, top_k

## Safe Modification Targets
1. eval/run_macd_simple.py — modify inference logic (alpha, beta, temperature, entropy, adaptive params)
2. scripts/eval_macd.sh — change CLI arguments (cd_alpha, cd_beta, new flags)
3. macd/optimization.py — modify PGD optimization (would require re-running pipeline steps 1-3)

## Risky Files (DO NOT MODIFY)
- eval/evaluate.py — metric computation logic
- data/questions_macd/ — test data, labels, splits
- data/videos/ — original test videos

## Data Flow
1. Questions: data/questions_macd/eventhallusion_mix.jsonl (193 questions, yesno task)
2. Original videos: data/videos/original/
3. Counterfactual videos: data/counterfactual_videos/eventhallusion/ (352 pre-generated .mp4)
4. Answers: data/answers/eventhallusion_macd_mix.jsonl (generated by inference)
5. Metrics: stdout JSON from eval/evaluate.py

## Known Levers
- cd_alpha (2.6): contrast strength
- cd_beta (0.0036): logit cutoff threshold
- temperature (0.7): logit scaling before argmax
- top_k (50): top-k filtering
- top_p (0.9): nucleus filtering
- objects_topk, pgd_steps, r_initial, mode: optimization pipeline params

## Optimization Objective
Multi-metric tradeoff: Improve Precision (hallucination mitigation) while maintaining Recall/F1/Accuracy
- Baseline: P=0.804, R=0.956, F1=0.873, Acc=0.803
