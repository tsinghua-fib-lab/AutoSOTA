# CVPR 2026 — AutoSOTA Optimized Repositories

This directory contains 16 CVPR 2026 paper repositories that were
post-hoc optimized by the AutoSOTA pipeline
(`tsinghua-fib-lab/AutoSOTA`).

Each `paper-<id>-<abbr>/` subdirectory holds:

- the slimmed source code of the original repository (datasets, weights,
  caches, and `.git/` history removed);
- a `Technical Report.md` documenting the original method, the identified
  limitations, the optimization methodology, and quantitative results.
