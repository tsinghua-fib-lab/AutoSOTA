This repository implements a FCM-VAE.

In this paper, we used ASD data from the ABIDE dataset. The preprocessed data provided by [1] are publicly available at [BrainIB_V2](https://github.com/SJYuCNEL/brain-and-Information-Bottleneck/tree/main/BrainIB_V2).

[1] Zheng, Kaizhong, et al. "Brainib: Interpretable brain network-based psychiatric diagnosis with graph information bottleneck." IEEE Transactions on Neural Networks and Learning Systems (2024).
