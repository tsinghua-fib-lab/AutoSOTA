## Data
You need to follow directory structure of the `data` as below.
```
${ROOT} 
|-- data  
|   |-- base_data
```
* Download `base_data` from [HuggingFace](https://huggingface.co/datasets/dqj5182/feco-data/blob/main/demo/data/base_data.tar.gz) by running:
```
bash scripts/download_demo_base_data.sh
```
