# Release validation scope

The source release preserves final active head numerical operations, metric code,
and historical configurations. Its training/inference wrapper was made portable
and now accepts arbitrary cohort sizes, rejects bilateral train/validation overlap,
and saves/loads heads with safe state-dictionary loading.

Release checks cover identity initialization, independent parameters, bounded
corrections, descriptor order, known ROC metrics, invalid IDs/cohort shapes,
synthetic optimization, checkpoint round-trip, baseline and label-aligned evaluation.
A separate original-versus-release parity check compares every fold's state,
output, loss and optimizer update against the verified source on artificial inputs.

These are software checks. They do not re-run the 300-epoch clinical experiment,
recover the exact external clinical cohort, validate clinical deployment, or prove
hidden-test generalization. Historical aggregate results are retained as evidence
of the prior experiment, not advertised as generated by this packaging session.

Verified on 2026-10-01: 16 CPU tests passed; all seven final heads matched the
original source bit for bit over four optimizer updates each; offline wheel build passed.

The installed wheel also completed the artificial-data CLI demonstration: training,
checkpoint save/load, baseline inference, adapted inference, and aligned evaluation.

Version 0.1.1 additionally separates data/training/inference/evaluation from CLI,
removes the disabled affine branch and checks Black formatting. All 16 tests and
seven-head numerical parity checks passed again. Formatting of metrics.py changes
its release-file bytes but leaves its parsed formula implementation unchanged;
historical hashes refer to the original protected source and artifacts.
