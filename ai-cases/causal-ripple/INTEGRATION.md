# AutoSOTA repository integration

**Archived: November 7, 2026.** Source package:
`AutoSOTA_Causal_Ripple_Research_Package_20261107.zip`.

The supplied English report, implementation, tests, result tables, task-outcome
vectors, figures, licenses, and evidence index are preserved. Python source files
are unchanged. The README installation example now uses this repository's archive
path. Four duplicate PDF figure exports are omitted; their PNG counterparts and
the SVG banner remain. The package checksum file is regenerated for this archive.
Two CSV tables use Git-normalized LF line endings; their values are unchanged.

The selected main results and Visible-Cascade extension are separate protocols.
In particular, the DS-1000 main configuration solves 55 tasks, while the cascade
input uses another configuration that solves 52. Matching serial-call ceilings
does not imply equal sequence-level compute. Repeated benchmark exposure and
other limitations remain in [the report](REPORT.md).

The integration checks compare stored task-outcome vectors with the reported
counts. They do not regenerate programs or run benchmark test code. The supplied
release/GPU validation records describe earlier checks, not a new validation run
on this integration machine.

See the common [source manifest](../source_manifest.json) for the source ZIP hash,
original and archived file hashes, and omitted files; see
[integration validation](../integration_validation.json) for checks performed here.
